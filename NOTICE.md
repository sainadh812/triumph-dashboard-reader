# Provenance

The inference implementation is adapted from this project's [experiment archive](https://github.com/sainadh812/triumph-speedometer-dataset/tree/7a3fd991d6c0e85e050e593c76fd895d59d516ed/dashboard_joint_v1). Model training used torchvision MobileNetV3-Small features. Dependencies retain their own licenses.

Demo frames come from project recordings. Historical synthetic-source images may include reconstructed or internet-sourced dashboard artwork; those original images are not bundled here. Triumph names identify the motorcycle; this is an independent project.

No additional redistribution license has been selected for this repository's code, weights or recordings.
